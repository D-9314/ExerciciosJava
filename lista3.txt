/*-------------------------------------------------------------------
  Ex 3.2: Senha do castelo
  - pedir uma senha
  - verificar se a senha está correta
  - informar se o acesso foi permitido ou negado

  TAREFA:
  - peça para o usuário digitar uma senha
  - considere que a senha correta é "dragao"
  - se a senha estiver correta, imprima:
      "Acesso permitido!"
  - caso contrário, imprima:
      "Senha incorreta!"

  ATENÇÃO:
  - a senha é uma String
  - para comparar duas Strings em Java, não use o operador ==
  - use o método .equals()

  EXEMPLO:
  - senha.equals("dragao")
  - essa expressão será true quando a variável senha contiver
    exatamente o texto "dragao"

  DESAFIO:
  - faça o programa aceitar a senha independentemente de letras
    maiúsculas ou minúsculas
  - por exemplo, "dragao", "Dragao" e "DRAGAO" devem ser aceitas
  - para isso, utilize o método .equalsIgnoreCase()

  EXEMPLO:
  - senha.equalsIgnoreCase("dragao")
-------------------------------------------------------------------*/

/*-------------------------------------------------------------------
  Ex 3.11: Senha até acertar
  - utilizar o comando WHILE para permitir várias tentativas
  - o usuário deve continuar tentando até informar a senha correta

  TAREFA:
  - considere que a senha correta é:

      "banana"

  - peça para o usuário informar a senha

  - enquanto a senha estiver errada, imprima:

      "Senha incorreta. Tente novamente."

  - peça a senha novamente

  - quando o usuário informar a senha correta, imprima:

      "Acesso permitido!"

  DICA:
  - utilize o comando while para repetir a tentativa
  - utilize o método .equals() para comparar Strings

  EXEMPLO:
      senha.equals("banana")

  - essa expressão será true quando a senha for exatamente "banana"

  ATENÇÃO:
  - não utilize == para comparar Strings
  - para repetir enquanto a senha estiver errada, você pode utilizar
    o operador !:

      !senha.equals("banana")

  - o operador ! significa "NÃO"

  DESAFIO:
  - faça o programa aceitar "banana", "BANANA", "Banana" etc.
  - utilize .equalsIgnoreCase() em vez de .equals()
-------------------------------------------------------------------*/
